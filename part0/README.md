# Part 0: Fundamentals of Web Apps

Solutions for Part 0 exercises of the [Full Stack Open](https://fullstackopen.com/) course, illustrating HTTP request/response cycles and Single Page Applications (SPAs) using Mermaid sequence diagrams.

## Included Exercises

* **0.4: New note (Traditional Web App)** (`0.4.md`) — Sequence diagram showing the request/response flow when submitting a new note in a traditional multi-page app (POST request, 302 redirect, and full page reload).
* **0.5: Single Page App Load** (`0.5.md`) — Sequence diagram illustrating how an SPA fetches its initial assets (HTML, CSS, `spa.js`, and `data.json`).
* **0.6: New note (Single Page App)** (`0.6.md`) — Sequence diagram mapping out the asynchronous creation of a new note in an SPA (`e.preventDefault()`, POST request, `201 Created`, and local DOM update).
