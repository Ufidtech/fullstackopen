# Full Stack Open 🚀

My personal repository containing solutions, exercises, and projects for the [Full Stack Open](https://fullstackopen.com/) course provided by the University of Helsinki.

## Course Structure & Progress

- **[Part 0: Fundamentals of Web Apps](./part0/)** — Exploration of web application foundations, HTTP request/response flows, and Single Page Applications (SPAs) mapped out via Mermaid sequence diagrams.
- **[Part 1: Introduction to React](./part1/)** *(Upcoming)* — Core concepts of React, component architecture, state management, and debugging.
